# XY Forever plan

The roadmap and work queue. The orchestrator ([ORCHESTRATION.md](ORCHESTRATION.md)) reads
this file, runs the next item with one agent, and updates it. After the cut (P.7), work is
claimed through GitHub Issues (one issue per item, assigned before work starts); this file
stays the roadmap. Product goals and settled rules: [GOALS.md](GOALS.md). Your own device
and session state: your local `docs/STATUS.md` (not in git). Budget: 160 lines. Finished
items leave this file; git history keeps them.

## Shape

One **file engine** (list, read, write, delete, make folder over `/yaffs2`, minus the
brick paths in SAFETY.md), running in our main loops with timeouts. Two doors onto it:

- **Serial protocol** (formal, published spec): commands, installs, automation, the web app.
- **Our own MTP responder**: standard file access with any MTP client.

Firmware, mods and content packs are "put a file, send install" through either door
or the on-device menu. Stock MTP (interrupt code that blocks on processor A) and its
watchdog recovery are abandoned: builds 139-150, do not continue them.

**Stock code is a driver layer, nothing more.** The stock 1.2.1 bootloader's
hardware drivers stay in use (storage, USB controller, link, screen, keys), each
checksum-verified before use. Hard rule from 007: processor B never waits on
processor A without a time limit. We call them as plain functions from our own loops. We
do not run stock features, drive stock state machines, or patch stock state. Item 0.3
lists what crosses that line today.

## Item fields

`ID | kind | title | needs | done when`. Kinds: **research** (read-only, ends in a
decision record), **build** (code + tests, one commit), **device** (the orchestrator
runs a script on the OP-XY; `safe` or `risky`), **review** (fresh agent checks a diff). Status is the mark
before the ID: `[ ]` todo, `[x]` done, `[!]` blocked (reason on the next line). A tilde in the
brackets marks the item an orchestrator took this sitting (ORCHESTRATION.md "One sitting"); a
committed one from another sitting counts as todo (its progress text stays).

## M8. One Open-XY firmware, set up like a BIOS

XY Forever keeps track of the selected mods and rebuilds only when the base firmware or the selection changes; the modded firmware, "Open-XY", is the default while mods are enabled. Changes (firmware version, mods) are pending like a BIOS: at boot XY Forever asks whether to save them; save builds the firmware (selected firmware as the root, mods applied, content moved) and boots; not saving exits to the OS. Booting official firmware while mods are configured is "Safe mode": "Boot without mods" confirms, resets content, boots stock and keeps the selection and the built firmware; "Restore Open-XY" brings it back without a rebuild; plus a fast "All off". Knobs: all four the same: turn moves one row, push selects like PLAY.
